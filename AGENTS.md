# AgentOS entry point
Read `.agent/AGENTS.md` for the shared agreement, `.agent/HANDOFF.md` for orientation,
and `.agent/config.json` for this project's coordination repository. Project rules
here take precedence over the generic agreement. Work only on the owner's assignment.

Run `python3 scripts/agentos.py doctor` before editing. AgentOS maintains records;
permissions must be enforced by GitHub and the deployment platform.
